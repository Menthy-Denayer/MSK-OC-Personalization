# Repository For Personalizing Predicitve MSK Simulations
- The "code" folder contains the code used for personalization, built on top of the PredSim framework.
- The "data" folder contains the data used for validation and a summary of the metrics.
- The "models" folder contains all of the MSK models used to run the simulations.
- The "results" folder contains all of the simulation results.

# Citation
A paper describing the personalization framework is currenlty submitted in the Journal of NeuroEngineering & Rehabilitation.
